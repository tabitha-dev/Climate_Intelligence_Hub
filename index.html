A NOTE ABOUT THIS PROJECT

Transparency is part of the experience.

This independent educational project separates historical modeled weather, future scenario projections and modeled air-quality forecasts. It does not show certified monitoring-station data, provide medical advice or predict local flood damage.

Built with HTML, CSS and JavaScript on GitHub Pages. Free API responses may be rate-limited or temporarily unavailable. If a request fails, the app explains the limitation instead of inventing a value.

Frequently asked questions

Are these climate measurements live?

No. The historical explorer shows ERA5 weather reanalysis, the sea-level section shows published IPCC projections, and the air-quality section shows modeled near-term forecasts. Each uses its own time scale and source.

Can I use this to assess flooding at my address?

No. Global mean sea-level rise is not the same as local coastal flood risk. Local elevation, land motion, tides and storm surge require specialist data.

Why isn't there a live climate news ticker?

The earlier free news API stopped working. Rather than display unverified or out-of-date headlines, this site links directly to NASA, NOAA and IPCC sources.

Does this site ask for my location?

No automatic geolocation permission is requested. You enter a city or ZIP code, and the location is sent to public geocoding and weather or air-quality data providers to retrieve results.
